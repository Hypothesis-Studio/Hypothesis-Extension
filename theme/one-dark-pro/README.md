# One Dark Pro

Atom's iconic One Dark theme, ported to Hypothesis Editor.

## Themes Included

- **One Dark Pro** — Rich dark theme with balanced contrast and warm tones
- **One Light Pro** — Clean light variant inspired by Atom's One Light

## Features

- Faithful port of Atom's One Dark color palette
- Full Monaco editor integration with token-level syntax colors
- Complete UI coverage (sidebar, status bar, tabs, panels)
- CSS variable injection for consistent workbench theming

## Usage

1. Install the extension via `.hyp` file or extension manager
2. Open **Settings → Color Theme**
3. Select **One Dark Pro** or **One Light Pro**
