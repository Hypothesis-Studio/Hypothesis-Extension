# Material Theme Pack

Professional Material Design-inspired theme pack for Hypothesis Editor.

## Themes Included

- **Material Dark** — Deep blue-grey palette with vibrant syntax highlighting
- **Material Light** — Clean, bright palette with soft contrast

## Features

- 120+ color definitions for complete UI coverage
- Full Monaco editor integration with custom token colors
- Automatic CSS variable injection for seamless theming
- Smooth switching between Dark and Light variants

## Usage

1. Install the extension via `.hyp` file or extension manager
2. Open **Settings → Color Theme**
3. Select **Material Dark** or **Material Light**
